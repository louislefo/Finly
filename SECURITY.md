# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

Finly handles sensitive local financial data and bank connector configurations. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please report security issues privately:
- Through GitHub Security Advisories: https://github.com/louislefo/Finly/security/advisories/new
- Or by emailing the project maintainer directly.

We appreciate your assistance in responsibly disclosing and verifying vulnerabilities.

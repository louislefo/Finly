# Contributing to Finly

Thank you for your interest in contributing to Finly.

## Development Workflow

1. Fork the repository and create your branch from `dev`.
2. Ensure your local environment is configured for both the backend (FastAPI, Python 3.11+) and frontend (Next.js 16, React 19).
3. Test your changes locally before opening a pull request.
4. Open a pull request against the `dev` branch.

## Code Standards

- **Language:** Code, comments, and documentation must be written in English.
- **UI Guidelines:** Dark mode first (OLED / Zinc 950 palette), minimal, crisp, using Shadcn UI tokens. Avoid unnecessary verbose descriptions or filter pills.
- **Tone & Text:** Do not include emojis in code, commits, documentation, or user interfaces.
- **Security:** Never commit credentials, private encryption keys, or personal financial test data.

## Issue Guidelines

- For bug reports, use the [Bug Report](https://github.com/louislefo/Finly/issues/new?template=bug_report.yml) template.
- For feature proposals, use the [Feature Request](https://github.com/louislefo/Finly/issues/new?template=feature_request.yml) template.
- For new banking integrations, use the [Bank Connector](https://github.com/louislefo/Finly/issues/new?template=bank_connector.yml) template.
- For general questions and setup advice, visit [GitHub Discussions](https://github.com/louislefo/Finly/discussions).
